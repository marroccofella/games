# ◆ 42.uk Arcade — Games

Games from the [42.uk](https://42.uk) Library. Four games live in self-contained folders; JACKO is linked from its own repository. Play them at **[marroccofella.github.io/games](https://marroccofella.github.io/games/)**.

| Game | Folder | What it is |
|------|--------|------------|
| **🍪 CRUMBLE INVADERS** | [`crumble-invaders/`](crumble-invaders/) | Created with [Promptus.ai](https://www.promptus.ai/), open source under MIT, and powered by an original rule-based gameplay engine. Bond invaders into allies, launch kookies, and defend emergency toilets. |
| **FREEL\*ADER 42: PROPERTY OVERFLOW** | [`freeloader-42/`](freeloader-42/) | Forty-two condemned digital properties, 126 evidence receipts, 42 properties + seven required archive remixes, visible goals, optional bonus audits, precision platforming, 2D/3D views, spiralling asterisk wormholes with layered stereo sound, and deadpan British failure. Latest: [2026.09.15-portal-recovery](freeloader-42/releases/2026.09.15-portal-recovery.html). |
| **◆ MOMM-MAN** | [`momm-man/`](momm-man/) | Eat every evidence dot, dodge the four review failure statuses, and turn them fail-closed. |
| **JACKO** | [Separate repository](https://github.com/marroccofella/jacko) | Yorkshire falling-block puzzle with a rotating oven. [Play](https://marroccofella.github.io/jacko/). |
| **@TEROIDS** | [`ateroids/`](ateroids/) | An asteroid shooter with collected-letter word scoring. Canonical development repo: [marroccofella/ateroids](https://github.com/marroccofella/ateroids). |
