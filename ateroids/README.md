# @TEROIDS

An arcade word shooter from the 42.uk Library. Rotate and thrust through an asteroid field, shoot rocks to release letters, then collect those letters for word scores.

**Controls:** Left/Right rotate, Up thrusts, Space shoots, B uses a smart bomb. On-screen buttons support touch.

**Play:** [/games/ateroids/](https://marroccofella.github.io/games/ateroids/) — landing page with a Play button (game at play.html) · canonical repository: [github.com/marroccofella/ateroids](https://github.com/marroccofella/ateroids) (also live at [/ateroids/](https://marroccofella.github.io/ateroids/))

## About this copy
This folder vendors the playable build into the games library so the arcade is complete in one place; the ateroids repository remains the canonical source for development. Fully static — no external services, accounts, or trackers.
