# FREEL*ADER 42 — Terms & Exterminations

Release: **2026.09.11-bug-hunt** · 11 September 2026

[Play the latest game](https://marroccofella.github.io/games/freeloader-42/play/?release=2026.09.11-bug-hunt)

If Willie enters a property he has already certified, its return visit becomes **BUG HUNT**: collect the glowing pixel blaster, defeat every enemy, then enter the asterisk portal. Original receipts and certificates stay earned. No extra detours or room-selection menu have been added.

Use **F**, **X**, or the on-screen **FIRE** button. Energy bolts guide themselves towards nearby enemies and pass through platforms; move closer if an enemy is out of range. Ammo is unlimited. The enemy counter, pickup glow, hit bursts and portal colour communicate the same events as the new pickup, shot and enemy effects. Both 2D and 3D share the combat rules and sprites.

Pause freezes combat. Retry, death and turning on Watch / Assist reset the encounter's weapon and enemies. An unfinished Bug Hunt can be resumed from its saved checkpoint. Clearing it opens the existing spinning wormhole and continues to the next unfinished property, without awarding duplicate campaign credit.

This update provides the first retro challenge mode. Additional 8-bit game types are planned. The current ordered campaign does not deliberately send players back to certified rooms; several different properties share a layout. Bug Hunt checks actual completion history, not a similar-looking map, and appears only on a real return visit.
